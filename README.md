# Theory of adhesion-driven self-organisation in growing tissues

Code accompanying the paper by Carles Falcó, Samuel Johnson, Mohit Dalwadi, and Philip Maini.

The Jupyter notebooks reproduce the figures in the main text, using the numerical solvers in `Solver1D.py` and `Solver2D.py`.

**Requirements**

```bash
pip install numpy scipy numba matplotlib jupyter
```
